# LearningNotes

> 个人学习笔记总仓——覆盖深度学习、NLP、强化学习、算法、数据结构、CV、LeetCode 等方向。

## 📌 项目概述

`LearningNotes` 是系统化整理的**学习笔记**仓库，把各技术方向的知识沉淀为 Markdown 与配套代码，便于复习、检索与二次整理。

## 📁 目录结构

```
LearningNotes/
├─ Algorithm/               # 算法
├─ DataStructure/           # 数据结构
├─ Leetcode/                # LeetCode 刷题
├─ DeepLearning/            # 深度学习（transformer / RoPE / BERT / ResNet 等）
├─ NLP-Notes/               # 自然语言处理
├─ ReinforcementLearning/   # 强化学习
├─ CV/                      # 计算机视觉
├─ Papers/                  # 论文阅读
├─ SelfProjects/            # 自研小项目
└─ 财经/                     # 财经金融
```

## 🚀 使用

按目录进入对应主题，直接阅读 Markdown 笔记；含代码的示例可独立运行。
